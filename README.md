# Personal Expense Tracker

A modern Android application for keeping track of your income and expenses built with Kotlin, Jetpack Compose, and Room database.

## Features

- **Summary Dashboard**: View total balance, total income, and total expenses.
- **Add Transactions**: Easily record income or expense transactions with amount, category, date, and description.
- **Dynamic Categories**: Automatically updates category lists depending on transaction type (Income vs Expense).
- **Transaction History**: View all transactions sorted by date with color-coded amounts (`+ ৳` for income, `- ৳` for expense).
- **Persistent Storage**: Uses Room Database for local persistence.
- **Delete Transactions**: Remove items from history with automatic balance updates.
